# KALA CHAKRA PWA — v16

Upload the contents of this folder to the root of the existing GitHub Pages repository.

Files:
- `index.html` — KALA CHAKRA Mobile v16
- `manifest.webmanifest` — installable app metadata
- `sw.js` — app-shell and offline caching
- `icons/` — app icons

Publish through GitHub Pages over HTTPS. The service worker requires HTTPS (or localhost).

Personal records remain in browser storage for that browser and device. This package has no user-facing export/import controls or cloud synchronisation. Existing records stored under a different origin or local-file context do not automatically transfer.
