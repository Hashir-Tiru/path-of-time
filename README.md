# KALA CHAKRA PWA — v8

Upload the contents of this folder to the root of the GitHub Pages repository.

Files:
- `index.html` — KALA CHAKRA app
- `manifest.webmanifest` — installable app metadata
- `sw.js` — app-shell and offline caching
- `icons/` — app icons

Publish through GitHub Pages over HTTPS. The service worker requires HTTPS (or localhost).

Personal records remain in the browser's local storage for that browser and device. This package does not include a user-facing export/import interface or cloud account synchronisation.
